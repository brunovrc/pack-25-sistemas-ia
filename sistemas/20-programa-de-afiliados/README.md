# Programa de Afiliados

> **Status: PLANEJADO.** Este sistema ainda NÃO está implementado nem disponível para uso.

**Público:** Empresas com programa de indicação ou afiliados
**Problema:** Indicações sem rastreio nem comissão clara
**Proposta:** Links rastreáveis, leads atribuídos e comissão com aprovação

## Escopo do MVP
- Parceiros
- Links rastreáveis
- Leads atribuídos
- Aprovação
- Cálculo de comissão

## Fora do escopo
- Pagamento automático

## Indicadores
- Leads por parceiro
- Conversão por parceiro
- Comissão a pagar

## Privacidade (LGPD)
Risco estimado: **médio**. Dados pessoais tratados: nome, e-mail, dados bancários opcionais para repasse manual.
Quem implanta o sistema é o controlador dos dados; este software não substitui assessoria jurídica.

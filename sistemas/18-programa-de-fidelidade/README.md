# Programa de Fidelidade

> **Status: PLANEJADO.** Este sistema ainda NÃO está implementado nem disponível para uso.

**Público:** Comércio e serviços com clientes recorrentes
**Problema:** Cartão de pontos em papel, sem controle
**Proposta:** Pontos, recompensas e resgates com extrato imutável

## Escopo do MVP
- Cadastro de clientes
- Saldo e pontos
- Recompensas
- Resgates
- Extrato

## Fora do escopo
- Carteira financeira
- Cashback em dinheiro

## Indicadores
- Pontos emitidos e resgatados
- Clientes ativos
- Taxa de resgate

## Privacidade (LGPD)
Risco estimado: **médio**. Dados pessoais tratados: nome, telefone, e-mail, histórico de consumo.
Quem implanta o sistema é o controlador dos dados; este software não substitui assessoria jurídica.

# Pesquisa NPS e Satisfação

> **Status: PLANEJADO.** Este sistema ainda NÃO está implementado nem disponível para uso.

**Público:** Empresas que querem medir satisfação de clientes
**Problema:** Sem medição contínua de satisfação
**Proposta:** Pesquisa pública NPS/CSAT com alertas para detratores e relatório

## Escopo do MVP
- Pesquisa pública
- NPS e CSAT
- Respostas
- Alertas de detratores
- Relatório

## Fora do escopo
- Envio em massa

## Indicadores
- NPS
- CSAT
- Taxa de resposta
- Detratores em aberto

## Privacidade (LGPD)
Risco estimado: **médio**. Dados pessoais tratados: e-mail opcional, comentários livres.
Quem implanta o sistema é o controlador dos dados; este software não substitui assessoria jurídica.

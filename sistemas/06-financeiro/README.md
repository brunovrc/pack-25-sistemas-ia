# Financeiro

> **Status: PLANEJADO.** Este sistema ainda NÃO está implementado nem disponível para uso.

**Público:** Pequenas empresas sem ERP
**Problema:** Contas a pagar e receber em planilhas, sem visão de caixa
**Proposta:** Controle de contas, categorias e fluxo de caixa com lançamentos auditáveis

## Escopo do MVP
- Contas a pagar
- Contas a receber
- Lançamentos imutáveis com estorno
- Categorias
- Fluxo de caixa
- Relatórios
- Exportação CSV

## Fora do escopo
- Contabilidade
- Emissão fiscal
- Conciliação bancária automática

## Indicadores
- Saldo projetado
- Inadimplência
- Despesa por categoria
- Prazo médio de recebimento

## Privacidade (LGPD)
Risco estimado: **alto**. Dados pessoais tratados: nome, CPF/CNPJ, dados financeiros.
Quem implanta o sistema é o controlador dos dados; este software não substitui assessoria jurídica.

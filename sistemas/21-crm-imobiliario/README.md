# CRM Imobiliário

> **Status: PLANEJADO.** Este sistema ainda NÃO está implementado nem disponível para uso.

**Público:** Imobiliárias e corretores autônomos
**Problema:** Interessados, imóveis e visitas controlados em planilhas e chats
**Proposta:** Funil de negociação com imóveis, visitas e ficha pública do interessado

## Escopo do MVP
- Imóveis
- Corretores
- Interessados
- Visitas
- Negociações
- Ficha pública

## Fora do escopo
- Integração com portais imobiliários
- Contrato com assinatura certificada

## Indicadores
- Visitas por negócio
- Conversão por corretor
- Tempo até fechamento

## Privacidade (LGPD)
Risco estimado: **alto**. Dados pessoais tratados: nome, CPF, telefone, renda declarada, endereço.
Quem implanta o sistema é o controlador dos dados; este software não substitui assessoria jurídica.

# Gestão de Contratos

> **Status: PLANEJADO.** Este sistema ainda NÃO está implementado nem disponível para uso.

**Público:** Empresas com contratos de clientes e fornecedores
**Problema:** Renovações e reajustes esquecidos
**Proposta:** Cadastro de contratos com arquivos, vencimentos e lembretes

## Escopo do MVP
- Contratos
- Partes
- Arquivos privados
- Vencimentos
- Lembretes
- Reajuste configurável

## Fora do escopo
- Parecer jurídico
- Assinatura certificada

## Indicadores
- Contratos a vencer em 30/60/90 dias
- Valor sob contrato
- Renovações

## Privacidade (LGPD)
Risco estimado: **alto**. Dados pessoais tratados: nome, CPF/CNPJ, endereço, documentos contratuais.
Quem implanta o sistema é o controlador dos dados; este software não substitui assessoria jurídica.

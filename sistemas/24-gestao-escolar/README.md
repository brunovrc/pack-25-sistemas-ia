# Gestão Escolar

> **Status: PLANEJADO.** Este sistema ainda NÃO está implementado nem disponível para uso.

**Público:** Escolas livres, cursos e reforço escolar
**Problema:** Matrículas, presença e parcelas em papel
**Proposta:** Matrículas, turmas, aulas, presença, parcelas e certificados administrativos

## Escopo do MVP
- Matrículas
- Turmas
- Aulas
- Presença
- Parcelas
- Certificados administrativos

## Fora do escopo
- Integração educacional governamental
- Diploma com validade oficial

## Indicadores
- Presença média
- Inadimplência
- Ocupação das turmas

## Privacidade (LGPD)
Risco estimado: **alto**. Dados pessoais tratados: nome, CPF, dados de menores (art. 14 LGPD), responsáveis, frequência.
Quem implanta o sistema é o controlador dos dados; este software não substitui assessoria jurídica.

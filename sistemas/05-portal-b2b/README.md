# Portal do Cliente B2B

> **Status: PLANEJADO.** Este sistema ainda NÃO está implementado nem disponível para uso.

**Público:** Empresas que atendem clientes corporativos recorrentes
**Problema:** Solicitações e documentos espalhados por e-mail
**Proposta:** Portal onde o cliente abre solicitações, acessa documentos e comenta, isolado por empresa

## Escopo do MVP
- Usuários clientes com acesso isolado
- Solicitações
- Documentos privados
- Comentários
- Notificações simples

## Fora do escopo
- Cobrança integrada
- Assinatura certificada

## Indicadores
- Solicitações abertas
- Tempo de resposta
- Documentos compartilhados

## Privacidade (LGPD)
Risco estimado: **médio**. Dados pessoais tratados: nome, e-mail, documentos do cliente.
Quem implanta o sistema é o controlador dos dados; este software não substitui assessoria jurídica.

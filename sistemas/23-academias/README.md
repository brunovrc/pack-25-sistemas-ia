# Gestão de Academias

> **Status: PLANEJADO.** Este sistema ainda NÃO está implementado nem disponível para uso.

**Público:** Academias e estúdios
**Problema:** Alunos, planos e mensalidades controlados à mão
**Proposta:** Alunos, planos, agenda, treinos montados pelo profissional e mensalidades administrativas

## Escopo do MVP
- Alunos
- Planos
- Agenda
- Exercícios criados pelo profissional
- Mensalidades administrativas

## Fora do escopo
- Prescrição clínica automática
- Cobrança integrada

## Indicadores
- Alunos ativos
- Evasão
- Inadimplência
- Frequência

## Privacidade (LGPD)
Risco estimado: **alto**. Dados pessoais tratados: nome, CPF, dados de saúde (sensíveis), medidas corporais.
Quem implanta o sistema é o controlador dos dados; este software não substitui assessoria jurídica.

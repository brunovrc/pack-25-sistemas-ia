# Pós-venda e Recompra

> **Status: PLANEJADO.** Este sistema ainda NÃO está implementado nem disponível para uso.

**Público:** Lojas e empresas com base de clientes recorrentes
**Problema:** Cliente compra uma vez e não é reativado
**Proposta:** Alertas de recompra e segmentação simples para contato ativo da equipe

## Escopo do MVP
- Cadastro de compras
- Cálculo de ciclo de recompra
- Segmentação simples
- Alertas de contato
- Registro de contatos

## Fora do escopo
- Disparo em massa
- Automação de WhatsApp

## Indicadores
- Taxa de recompra
- Clientes inativos
- Intervalo médio entre compras
- Contatos realizados

## Privacidade (LGPD)
Risco estimado: **médio**. Dados pessoais tratados: nome, telefone, e-mail, histórico de compras.
Quem implanta o sistema é o controlador dos dados; este software não substitui assessoria jurídica.

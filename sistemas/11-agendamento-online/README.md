# Agendamento Online

> **Status: PLANEJADO.** Este sistema ainda NÃO está implementado nem disponível para uso.

**Público:** Clínicas, salões e prestadores com agenda
**Problema:** Agenda no papel ou chat, com conflitos e faltas
**Proposta:** Reserva pública com disponibilidade real, bloqueios e reagendamento

## Escopo do MVP
- Profissionais
- Serviços
- Disponibilidade
- Reserva pública
- Bloqueios
- Reagendamento e cancelamento

## Fora do escopo
- Gateway de pagamento
- Videochamada

## Indicadores
- Taxa de ocupação
- Taxa de falta
- Reservas por serviço

## Privacidade (LGPD)
Risco estimado: **médio**. Dados pessoais tratados: nome, telefone, e-mail, horários de atendimento.
Quem implanta o sistema é o controlador dos dados; este software não substitui assessoria jurídica.

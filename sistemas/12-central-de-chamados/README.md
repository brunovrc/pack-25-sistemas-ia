# Central de Chamados

> **Status: PLANEJADO.** Este sistema ainda NÃO está implementado nem disponível para uso.

**Público:** Equipes de suporte interno ou externo
**Problema:** Pedidos de suporte perdidos e sem prazo
**Proposta:** Tickets com SLA, responsáveis, notas e métricas

## Escopo do MVP
- Tickets
- Status
- SLA
- Equipe
- Notas internas
- Anexos
- Métricas

## Fora do escopo
- Telefonia integrada
- Chat em tempo real

## Indicadores
- Tempo de primeira resposta
- Tempo de resolução
- SLA cumprido
- Backlog

## Privacidade (LGPD)
Risco estimado: **médio**. Dados pessoais tratados: nome, e-mail, conteúdo do chamado, anexos.
Quem implanta o sistema é o controlador dos dados; este software não substitui assessoria jurídica.

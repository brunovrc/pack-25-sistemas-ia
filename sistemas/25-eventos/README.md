# Eventos e Credenciamento

> **Status: PLANEJADO.** Este sistema ainda NÃO está implementado nem disponível para uso.

**Público:** Organizadores de eventos, workshops e congressos
**Problema:** Inscrição e check-in manuais, sem controle de capacidade
**Proposta:** Inscrições com lotes, ingressos QR assinados, check-in único e controle de presença

## Escopo do MVP
- Inscrições
- Lotes sem pagamento
- Ingressos com QR assinado
- Check-in único
- Capacidade
- Presença

## Fora do escopo
- Cobrança de ingressos
- Streaming

## Indicadores
- Inscritos vs. capacidade
- Taxa de comparecimento
- Check-ins por hora

## Privacidade (LGPD)
Risco estimado: **médio**. Dados pessoais tratados: nome, e-mail, documento opcional.
Quem implanta o sistema é o controlador dos dados; este software não substitui assessoria jurídica.
